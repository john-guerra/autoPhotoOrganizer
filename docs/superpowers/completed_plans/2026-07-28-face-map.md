# Face Map Implementation Plan (#232)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A registry view showing every person as a dot in a 2-D projection of their face embeddings, where you lasso a region and merge the caught people into one named person, undoably.

**Architecture:** The projection runs in a `worker_threads` worker (umap-js's `initializeFit` is a 14.1 s unyieldable call with a 1.8 GB peak — it cannot run on the API event loop, and `worker.terminate()` is the only cancel that works during it). Results are cached in SQLite keyed by canonicalised params and served via `INNER JOIN persons`, so merged-away dots vanish with no re-projection. The canvas scatter is split into pure modules plus a data-agnostic `ScatterCanvas.svelte` that never learns what a point means, which is what makes #165 an entry plus a component.

**Tech Stack:** Node 24, `worker_threads`, `umap-js` (Apache-2.0), better-sqlite3, Svelte 5 runes, d3-quadtree, canvas 2D, vitest, Playwright.

**Spec:** `docs/superpowers/specs/2026-07-28-face-map-design.md`
**Evidence:** `docs/experiments/2026-07-28-face-projection/` (measurements + architecture review)

 *   Keys this view handles ITSELF. Two consumers, and both matter:
 *   `ShortcutsOverlay` renders them (so a view's shortcuts cannot ship

/** @param {string} id @returns {Array<{keys: string[], label: string}>} */
export function viewKeys(id) {
  return getView(id).keys ?? [];
}

/**
 * Does this view handle `key` itself? Consulted by App before it refuses a
 * keystroke on capability grounds — a declared key is the view's business.
 * @param {string} id @param {string} key a KeyboardEvent.key value
 */
export function claimsKey(id, key) {
  const k = key.toLowerCase();
  return viewKeys(id).some((row) =>
    row.keys.some((declared) => declared.toLowerCase() === k)
  );
}

function seed() {

    const b = Array.from(personCentroids(db, "m", { minFaces: 2 }).ids);
    expect(a).toEqual(b);
    expect(a).toEqual([10, 20, 30]);

```js
import { dequantize } from "../ml/quantize.js";

/**
 * One unit-norm centroid per person, as a flat Float32Array.
 *
 * Flat rather than an array of arrays for the reason `faceVectors` gives: at
 * 25,758 x 512 an array-of-arrays is 25,758 objects for the GC to walk. The
 * worker converts to the nested form umap-js wants exactly once, then drops
 * this buffer.
 *
 * @param {import("better-sqlite3").Database} db
 * @param {string} model
 * @param {{minFaces?: number}} [opts] `minFaces` is a RUN parameter, not a
 *   cosmetic filter — a projection of a subset is not a subset of the
 *   projection, so filtering after the fact would leave the survivors'
 *   positions still shaped by everyone who was excluded.
 * @returns {{ids: Int32Array, dim: number, data: Float32Array, faceCounts: Int32Array}}
 */
export function personCentroids(db, model, { minFaces = 2 } = {}) {
  const rows = db
    .prepare(
      `SELECT f.person_id AS pid, f.dim, f.scale, f.vec
         FROM photo_faces f
        WHERE f.model = ? AND f.person_id IS NOT NULL
          AND f.person_id IN (
            SELECT person_id FROM photo_faces
             WHERE model = ? AND person_id IS NOT NULL
             GROUP BY person_id HAVING COUNT(*) >= ?)
        ORDER BY f.person_id, f.id`
    )
    .all(model, model, Math.max(1, minFaces | 0));

  if (!rows.length) {
    return {
      ids: new Int32Array(0),
      dim: 0,
      data: new Float32Array(0),
      faceCounts: new Int32Array(0),
    };
  }

  const dim = rows[0].dim;
  // Mirrors faceVectors' guard: a mixed-width result cannot be laid out flat,
  // and truncating to the first row's width compares garbage. It means two
  // models wrote under one name, which is worth stopping for.
  const odd = rows.find((r) => r.dim !== dim);
  if (odd) {
    throw new Error(
      `face vectors for ${model} have mixed dimensions (${dim} and ${odd.dim})`
    );
  }

  /** @type {Map<number, {v: Float64Array, n: number}>} */
  const acc = new Map();
  for (const r of rows) {
    let a = acc.get(r.pid);
    if (!a) acc.set(r.pid, (a = { v: new Float64Array(dim), n: 0 }));
    const bytes = new Int8Array(
      r.vec.buffer,
      r.vec.byteOffset,
      r.vec.byteLength
    );
    const f = dequantize(bytes, r.scale);
    for (let i = 0; i < dim; i++) a.v[i] += f[i];
    a.n++;
  }

  const ids = new Int32Array(acc.size);
  const faceCounts = new Int32Array(acc.size);
  const data = new Float32Array(acc.size * dim);
  let row = 0;
  // Map preserves insertion order and the query is ORDER BY person_id, so this
  // is ascending person id — the deterministic member order the cache needs.
  for (const [pid, a] of acc) {
    ids[row] = pid;
    faceCounts[row] = a.n;
    let norm = 0;
    for (let i = 0; i < dim; i++) norm += a.v[i] * a.v[i];
    norm = Math.sqrt(norm) || 1;
    const base = row * dim;
    for (let i = 0; i < dim; i++) data[base + i] = a.v[i] / norm;
    row++;
  }
  return { ids, dim, data, faceCounts };
}
```

 *
 * A pure function rather than markup, because "is t-SNE offered at 25,758
 * people?" should be a unit test, not something to eyeball in a dropdown.
 *
 * The notes carry MEASURED numbers (docs/experiments/2026-07-28-face-projection).
 * Splitting each person's faces into an earliest and a latest half >=24h apart
 * and measuring the twin's 2-D rank: t-SNE 62.5% nearest / 93.1% top-5, UMAP
 * 27.8% / 58.3%, PCA 2.8% / 6.9%. MDS (2.8%) and SQDMDS (0.0%, median rank
 * 1822) are deliberately absent: an option that measures at chance is a trap,
 * and SQDMDS scores 100% on a naive benchmark, so it will be re-proposed.
 */

/** t-SNE is O(n^2): 74s at 4,072 points measured, so ~47 min at 25,758. */
export const TSNE_MAX_MEMBERS = 6000;

export const ALGORITHMS = Object.freeze([
  {
    id: "umap",
    label: "UMAP",
    note: "Balanced. Finds the same person 58% of the time in the top 5.",
  },
  {
    id: "tsne",
    label: "t-SNE",
    note: "Slower, best separation — 93% in the top 5. Small maps only.",
  },
  {
    id: "pca",
    label: "PCA",
    note: "Instant, poor separation (7% in the top 5). For sanity checks.",
  },
]);

/**
 * @param {number} memberCount
 * @returns {Array<{id:string,label:string,note:string,enabled:boolean,reason:string}>}
 */
export function offerableAlgorithms(memberCount) {
  const n = Number(memberCount) || 0;
  return ALGORITHMS.map((a) => {
    if (a.id === "tsne" && n > TSNE_MAX_MEMBERS) {
      return {
        ...a,
        enabled: false,
        reason: `t-SNE needs ${TSNE_MAX_MEMBERS.toLocaleString()} people or fewer — raise the minimum faces to shrink the map.`,
      };
    }
    return { ...a, enabled: true, reason: "" };
  });
}

/** @param {string} id @param {number} memberCount */
export function isOfferable(id, memberCount) {
  const row = offerableAlgorithms(memberCount).find((a) => a.id === id);
  return Boolean(row?.enabled);
}

/**
 * The projection worker (#232).
 *
 * INVARIANT: this file never touches SQLite and imports nothing native. The
 * parent reads centroids, transfers a Float32Array, this returns coordinates,
 * the parent writes. So better-sqlite3's ABI trap (AGENT-NOTES, "a one-way
 * switch") stays entirely outside it, there is nothing to electron-rebuild,
 * and the whole dependency surface is umap-js.
 *
 * It runs in a worker THREAD rather than on the event loop because umap-js's
 * initializeFit is a single 14.1-second call with no callback at 25,758
 * points, peaking at 1.8 GB. There is no yield point to budget, so #231's fix
 * does not apply, and worker.terminate() is the only cancel that works during
 * it.
 */
import { parentPort, workerData } from "node:worker_threads";
import { UMAP } from "umap-js";

/** Deterministic PRNG. umap-js's `random` takes a function, and a seeded one
 *  is what makes the run cache correct — see runProjection.test.js. Four lines
 *  of mulberry32 rather than a dependency. */
function mulberry32(seed) {
  let a = seed >>> 0;
  return function () {
    a = (a + 0x6d2b79f5) | 0;
    let t = Math.imul(a ^ (a >>> 15), 1 | a);
    t = (t + Math.imul(t ^ (t >>> 7), 61 | t)) ^ t;
    return ((t ^ (t >>> 14)) >>> 0) / 4294967296;
  };
}

const post = (msg) => parentPort.postMessage(msg);

function toRows(buf, n, dim) {
  const rows = new Array(n);
  for (let i = 0; i < n; i++)
    rows[i] = Array.from(buf.subarray(i * dim, (i + 1) * dim));
  return rows;
}

function flatten(pairs, n) {
  const out = new Float32Array(n * 2);
  for (let i = 0; i < n; i++) {
    out[i * 2] = pairs[i][0];
    out[i * 2 + 1] = pairs[i][1];
  }
  return out;
}

async function main() {
  const { buffer, n, dim, algorithm, params } = workerData;
  let flat = new Float32Array(buffer);
  const rows = toRows(flat, n, dim);
  // Drop the flat view before the graph phase peaks — 52.8 MB at production
  // size, and V8 cannot reclaim it while this binding lives.
  flat = null;

  if (algorithm !== "umap") {
    throw new Error(`unknown algorithm: ${algorithm}`);
  }

  const nEpochs = params.nEpochs ?? 200;
  post({ type: "phase", phase: "Building the neighbour graph" });

  const umap = new UMAP({
    nComponents: 2,
    nNeighbors: params.nNeighbors ?? 15,
    minDist: params.minDist ?? 0.1,
    nEpochs,
    random: mulberry32(params.seed ?? 1212),
  });
  umap.initializeFit(rows);

  post({ type: "phase", phase: "Laying out" });
  // Epochs are UNIFORM work, unlike clusterFaces' upper triangle, so an
  // epoch-index bar is honest here. The "work, not items" rule does not bite.
  for (let i = 0; i < nEpochs; i++) {
    umap.step();
    if (i % 8 === 0) post({ type: "progress", done: i, total: nEpochs });
  }
  post({ type: "progress", done: nEpochs, total: nEpochs });

  const xy = flatten(umap.getEmbedding(), n);
  post({ type: "done", xy }, [xy.buffer]);
}

main().catch((e) => {
  // Rethrow so the parent's 'error' event carries a real Error with a stack.
  setTimeout(() => {
    throw e;
  });
});

```js
import { Worker } from "node:worker_threads";

const WORKER_URL = new URL("./worker.js", import.meta.url);

/** A generous ceiling that still turns an OOM into a CATCHABLE job failure
 *  rather than a process crash. Measured peak is 824 MB at the default
 *  minFaces of 2, and 1,825 MB with singletons included. */
export const MAX_OLD_GENERATION_MB = 3072;

/**
 * Run a projection in a worker thread.
 *
 * @param {object} o
 * @param {Float32Array} o.data  n * dim, row-major. TRANSFERRED — do not reuse.
 * @param {number} o.dim
 * @param {number} o.n
 * @param {string} o.algorithm
 * @param {object} o.params
 * @param {AbortSignal} [o.signal]
 * @param {(phase: string) => void} [o.onPhase]
 * @param {(p: {done:number,total:number}) => void} [o.onProgress]
 * @returns {Promise<Float32Array>} length 2n, interleaved x,y
 */
export function runProjection({
  data,
  dim,
  n,
  algorithm,
  params,
  signal,
  onPhase,
  onProgress,
}) {
  return new Promise((resolve, reject) => {
    const buffer = data.buffer.slice(
      data.byteOffset,
      data.byteOffset + data.byteLength
    );
    const worker = new Worker(WORKER_URL, {
      workerData: { buffer, n, dim, algorithm, params },
      transferList: [buffer],
      resourceLimits: { maxOldGenerationSizeMb: MAX_OLD_GENERATION_MB },
    });

    // `error` and `exit` RACE to settle this promise. Settle once, or the
    // double-settle takes the server down — the #killChild lesson in
    // OnnxMLService.js, copied rather than re-derived.
    let settled = false;
    const finish = (fn, v) => {
      if (settled) return;
      settled = true;
      cleanup();
      worker.terminate();
      fn(v);
    };

    const onAbort = () => {
      const e = new Error("canceled");
      e.name = "AbortError";
      finish(reject, e);
    };
    function cleanup() {
      signal?.removeEventListener("abort", onAbort);
    }
    if (signal?.aborted) return onAbort();
    signal?.addEventListener("abort", onAbort);

    worker.on("message", (msg) => {
      switch (msg.type) {
        case "phase":
          onPhase?.(msg.phase);
          break;
        case "progress":
          onProgress?.({ done: msg.done, total: msg.total });
          break;
        case "done":
          finish(resolve, msg.xy);
          break;
        default:
          // A frame we do not know is not an error — the protocol reserves
          // {type:"embedding"} for a streaming variant.
          break;
      }
    });
    worker.on("error", (e) => finish(reject, e));
    worker.on("exit", (code) => {
      if (code !== 0) {
        finish(reject, new Error(`projection worker exited with code ${code}`));
      } else {
        finish(reject, new Error("projection worker exited without a result"));
      }
    });
  });
}

import { createHash } from "node:crypto";

/**
 * A stable digest of a params object.
 *
 * Canonicalised rather than raw JSON: `{"a":1,"b":2}` and `{"b":2,"a":1}` are
 * the same run, and keying on the raw text would compute it twice and cache
 * it twice.
 * @param {object} obj @returns {string}
 */
export function paramsKey(obj) {
  const canon = (v) => {
    if (Array.isArray(v)) return v.map(canon);
    if (v && typeof v === "object") {
      return Object.fromEntries(
        Object.keys(v)
          .sort()
          .map((k) => [k, canon(v[k])])
      );
    }
    return v;
  };
  return createHash("sha1")
    .update(JSON.stringify(canon(obj)))
    .digest("hex");
}

export function findRun(db, { kind, model, algorithm, paramsKey: pk }) {
  return (
    db
      .prepare(
        `SELECT * FROM projection_runs
          WHERE kind = ? AND model = ? AND algorithm = ? AND params_key = ?
          ORDER BY id DESC LIMIT 1`
      )
      .get(kind, model, algorithm, pk) ?? null
  );
}

export function createRun(
  db,
  {
    kind,
    model,
    algorithm,
    paramsKey: pk,
    params,
    members,
    createdAt = Date.now(),
  }
) {
  const { lastInsertRowid } = db
    .prepare(
      `INSERT INTO projection_runs
         (kind, model, algorithm, params_key, params, members, created_at)
       VALUES (?, ?, ?, ?, ?, ?, ?)`
    )
    .run(
      kind,
      model,
      algorithm,
      pk,
      JSON.stringify(params),
      members,
      createdAt
    );
  return Number(lastInsertRowid);
}

export function savePoints(db, runId, ids, xy) {
  const ins = db.prepare(
    `INSERT OR REPLACE INTO projection_point (run_id, ref_id, x, y)
     VALUES (?, ?, ?, ?)`
  );
  db.transaction(() => {
    for (let i = 0; i < ids.length; i++) {
      ins.run(runId, ids[i], xy[i * 2], xy[i * 2 + 1]);
    }
  })();
}

/**
 * The run's points, joined to the LIVE persons table.
 * @returns {Array<{personId:number,x:number,y:number,name:string|null,faces:number,coverFaceId:number|null}>}
 */
export function pointsForRun(db, runId) {
  return db
    .prepare(
      `SELECT pp.ref_id AS personId, pp.x AS x, pp.y AS y,
              p.name AS name, p.cover_face_id AS coverFaceId,
              (SELECT COUNT(*) FROM photo_faces f WHERE f.person_id = p.id) AS faces
         FROM projection_point pp
         JOIN persons p ON p.id = pp.ref_id
        WHERE pp.run_id = ?
        ORDER BY pp.ref_id`
    )
    .all(runId);
}

/** Keep the newest `keep` runs for this (kind, model); drop the rest with their points. */
export function pruneRuns(db, { kind, model, keep = 3 }) {
  db.transaction(() => {
    const doomed = db
      .prepare(
        `SELECT id FROM projection_runs
          WHERE kind = ? AND model = ?
          ORDER BY created_at DESC, id DESC
          LIMIT -1 OFFSET ?`
      )
      .all(kind, model, keep)
      .map((r) => r.id);
    for (const id of doomed) {
      db.prepare(`DELETE FROM projection_point WHERE run_id = ?`).run(id);
      db.prepare(`DELETE FROM projection_runs WHERE id = ?`).run(id);
    }
  })();
}

/** The ONE definition of screen<->data. Hover, lasso and draw all read it, so
 *  they cannot disagree — the bug `albumTimeline.js`'s hitAt exists to stop. */

export const MIN_ZOOM = 0.05;
export const MAX_ZOOM = 400;

export const clampZoom = (k) => Math.min(MAX_ZOOM, Math.max(MIN_ZOOM, k));

/** @param {number} x @param {number} y @param {{k:number,tx:number,ty:number}} t */
export function toScreen(x, y, t) {
  return [x * t.k + t.tx, y * t.k + t.ty];
}

export function toData(px, py, t) {
  return [(px - t.tx) / t.k, (py - t.ty) / t.k];
}

/** A transform that fits every point inside `w` x `h` with `pad` px to spare. */
export function fitExtent(xs, ys, w, h, pad = 24) {
  if (!xs.length) return { k: 1, tx: w / 2, ty: h / 2 };
  let minX = Infinity,
    maxX = -Infinity,
    minY = Infinity,
    maxY = -Infinity;
  for (let i = 0; i < xs.length; i++) {
    if (xs[i] < minX) minX = xs[i];
    if (xs[i] > maxX) maxX = xs[i];
    if (ys[i] < minY) minY = ys[i];
    if (ys[i] > maxY) maxY = ys[i];
  }
  // A degenerate extent (every point identical) would divide by zero and put
  // k at Infinity, which paints nothing and reads as a broken view.
  const spanX = maxX - minX || 1;
  const spanY = maxY - minY || 1;
  const k = clampZoom(Math.min((w - 2 * pad) / spanX, (h - 2 * pad) / spanY));
  return {
    k,
    tx: w / 2 - ((minX + maxX) / 2) * k,
    ty: h / 2 - ((minY + maxY) / 2) * k,
  };
}

/** @param {Float32Array} xs @param {Float32Array} ys */
export function buildIndex(xs, ys) {
  const idx = Array.from({ length: xs.length }, (_, i) => i);
  const t = quadtree()
    .x((i) => xs[i])
    .y((i) => ys[i])
    .addAll(idx);
  t._xs = xs;
  t._ys = ys;
  return t;
}

/**
 * Index of the nearest point within `radius`, or -1.
 * -1 rather than null, matching `hitAt`'s existing convention.
 */
export function nearest(index, x, y, radius) {
  const found = index.find(x, y, radius);
  return found === undefined ? -1 : found;
}

/**
 * Ray casting. Deliberately NOT "is it on the boundary" aware: what matters is
 * that the answer is a boolean and that it is the SAME on every call, or a
 * point flickers in and out of a selection as the polygon is redrawn.
 */
export function pointInPolygon(x, y, poly) {
  let inside = false;
  for (let i = 0, j = poly.length - 1; i < poly.length; j = i++) {
    const [xi, yi] = poly[i];
    const [xj, yj] = poly[j];
    if (yi > y !== yj > y && x < ((xj - xi) * (y - yi)) / (yj - yi) + xi) {
      inside = !inside;
    }
  }
  return inside;
}

export function polygonBBox(poly) {
  let minX = Infinity,
    minY = Infinity,
    maxX = -Infinity,
    maxY = -Infinity;
  for (const [x, y] of poly) {
    if (x < minX) minX = x;
    if (x > maxX) maxX = x;
    if (y < minY) minY = y;
    if (y > maxY) maxY = y;
  }
  return [minX, minY, maxX, maxY];
}

/**
 * Indices inside `poly`. Prunes with the quadtree's bbox visit first, so the
 * cost is proportional to what the lasso actually encloses rather than to the
 * whole map.
 */
export function caught(index, poly) {
  if (!poly || poly.length < 3) return [];
  const [minX, minY, maxX, maxY] = polygonBBox(poly);
  const xs = index._xs;
  const ys = index._ys;
  const out = [];
  index.visit((node, x0, y0, x1, y1) => {
    if (x0 > maxX || x1 < minX || y0 > maxY || y1 < minY) return true; // prune
    if (!node.length) {
      let leaf = node;
      do {
        const i = leaf.data;
        if (pointInPolygon(xs[i], ys[i], poly)) out.push(i);
      } while ((leaf = leaf.next));
    }
    return false;
  });
  return out;
}
```
